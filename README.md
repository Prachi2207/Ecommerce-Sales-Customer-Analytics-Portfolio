# Ecommerce-Sales-Customer-Analytics-Portfolio
E-commerce Sales &amp; Customer Analytics using Python, MySQL, Power Bi and Excel
E-Commerce Sales & Customer Analytics

Project Overview

This project focuses on analyzing e-commerce sales performance, customer behavior, product profitability, and regional trends using data analytics tools.

Business Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Understand customer segments and purchasing behavior.
- Compare sales performance across regions.
- Track monthly sales trends and order status.

Tools & Technologies

- Power BI: Interactive dashboards and data visualization
- Python: Data analysis and business insights
- MySQL: Database management and SQL analysis
- Microsoft Excel: Data validation and preparation

Key Business Insights

- The West region recorded the highest revenue among the analyzed regions.
- July was the highest-performing month for sales in the analysis.
- Electronics, Home & Kitchen, and Clothing showed different profit contributions.
- Delivered orders represented the largest order-status group.
